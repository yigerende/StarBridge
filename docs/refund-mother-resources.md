## 数据和权限

所有新接口位于 `/api/admin/refund/mother-management`，由统一后台管理员鉴权。普通用户及客户 API 不提供母号凭据或管理能力；响应不缓存，凭据加密保存，不写浏览器存储。

管理操作和原代退队列使用同一事务锁，按团队及子号持有短时租约。管理期间不能抢占资源、更换身份或删除母号；启停只改变后续接单资格。原退款 worker 和 Python runtime 仍保持原来源内容。

列表只展示数据库中最后查询的资料，批量刷新才访问上游。当前成员数量不等同当前正在办理的订单数。套餐参考价不参与扣费，累计服务费取实际已结算记录。更换凭据清理旧查询结果，失败查询不会拿别的团队资料替代。
