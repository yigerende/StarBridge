正式订阅当前使用 IPRoyal 国家代理池，粘性会话有效期 3600 秒。本次调整该模式的付款前网络重试：

- 在确认未提交付款、未付款成功，且未耗尽网络重试次数时，原子撤销本轮代理绑定，并清空当前结账链接和加密请求上下文。

- 原供应商会话 ID 保留在防重表，供应商返回旧 ID 时拒绝复用。新的会话不等于保证获得不同出口 IP，不额外查询出口。
- 付款已提交但结果未知：继续使用原交易及原代理只读核实，不能把缺少成功响应当成未扣款，也不清除提交防重标记。
- 付款成功后：不撤销绑定，不重提链或付款；现有恢复队列使用原代理，按后续核实次数和间隔重试。代理过期或次数耗尽后转待核实，不偷偷换代理。
- 设备标识缺失、拒付、403、参数错误、代理池容量等待等不新增换代理重试。人工代理模式沿用原有规则。
