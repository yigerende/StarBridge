- 按真实路由核对方法、鉴权、请求标识、可选参数、字段来源、分页及响应。注册核心文档快照保持来源一致，星桥客户用语和统一会员字段在现有文档组装层补齐。

- 删除运营管理、旧版本兼容和内部执行说明；保留费用单位、权限和错误处理等调用方必要信息。
- 322 个响应示例通过 JSON Schema 校验；32 个操作编号唯一、全部字段及参数有说明、引用可解析。真实隔离接口测试覆盖可调用列表、当前响应、资金和权限。浏览器检查 46 个文档锚点、1440/390px 页面、控制台零错误。
