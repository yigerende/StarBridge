# 代理恢复检测与运营当前阶段

## 行为与配置

- 订阅资源与调度 → 手动代理配置：恢复连接测试次数默认 3，恢复测试间隔默认 5 秒。
- 代退资源与调度 → 调度与恢复：子号代理采用同样默认值，独立保存。母号专属代理不参与。
- 次数允许 1～20；留空保存为 null，冷却结束直接恢复。间隔允许 1～300 秒，从上一轮检测结束计时。
- 故障冷却结束后，后台以新连接独立检测，不借真实订单探测。连续达到指定次数才重新允许分配；失败清零并重新进入原故障冷却。
- 不自动开启运营停用的代理，不更改主备顺序，不更改正在执行订单的付款/代退结果、冻结资金或扣费。已删除或未配置的子号代理不参与恢复。
- 数据库租约和令牌防止重复检测；配置变更、新故障、代理编辑和租约过期均阻止旧结果恢复资源。维护更新等待检测结束。
- 列表显示冷却到期、恢复检测中及连续成功次数。手动测试仅作诊断，不绕过自动恢复要求。

## 当前阶段

运营订单中心的注册、订阅、代退列表及运营办理总览增加“当前阶段”。按持久化执行记录批量查询，使用固定阶段名称，不返回原始日志或凭据。用户端列表不变；原注册执行核心及原代退 runtime/refundworker 不改。
