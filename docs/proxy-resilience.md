# 订阅国家代理与代退子号主备代理

2026-11-11。用户授权完成两项功能、推送 GitHub 并更新星桥正式环境。原注册及 HUIXU 协议执行源码不变；新管理和调度接入独立，不复制旧项目资源。

## 订阅

订阅资源与调度包含三种互斥模式：手动代理、独立会话代理、国家代理。原 `country_pool` 配置和值不变，名称改为独立会话代理。新国家代理使用 `national_pool`，复用注册平台的 ProxyService、国家目录、711/B2/1024/CLI/IPRoyal 供应商和库存检测组件。

国家池目录位于持久卷 `.registration-runtime/subscription-country-proxies`，供应商密钥及白名单所有权独立保存；注册池不读写此目录。数据库 `subscription_country_entries` 保存加密端点，`subscription_country_usage` 保存跨进程占用与冷却。供应商变更期间锁住新分配，已绑定任务继续使用自己的地址；独立连通性检测不阻塞业务分配。

每笔订阅按国家取一条，缺少专属国家时可用 GLOBAL；不添加 session、sid 或改变密码。订单、付款核实、付款后恢复沿用原地址。原始供应商粘性仍由来源参数控制，不保证供应商之外的固定 IP。独立续费按配置默认国家选取并绑定。

使用中绝不重复分配。完成后从释放时刻按粘性分钟数冷却，重启保留。与注册原规则相同：优先未冷却；可选项全部冷却时可回退未占用条目。删除目录不删除历史绑定；人工恢复旧单时如已被另一单占用则等待，不能抢占。

代理配置与库存只开放管理员接口，主网关和注册接入双重鉴权。普通客户/API 不返回供应商凭据。公开用户接口契约不变，不把管理接口添加到用户文档。

## 代退

每条代理适用对象为母号、子号或通用。原有代理默认通用，原子号全局代理保留为主用，备用初始为空，不替管理员猜测供应商用途。

调度配置支持一个主用、有序多选备用和 30～3600 秒故障冷却（默认300秒）。明确子号传输/代理错误才标记故障，原安全重试阶段按配置选择下一条可用代理；原订单、母号、冻结费用和执行步骤不变。账号密码错误、挑战、普通429及母号错误不会触发子号切换。

故障状态全局持久保存。新单避开冷却代理；到期只放一笔探测，其余订单继续使用健康备用，成功后新单优先主用。全部不可用时等待，不计额外重试、不直连，不阻塞只需母号的收尾。管理员成功检测或修改代理地址可解除旧故障；晚到旧检测/旧任务成功不能覆盖更新的故障。

退款提交结果不明仍进入原核实/兜底阶段，换代理不能重新提交。重试次数、间隔、恢复开关和原业务成功条件保持有效。关闭自动恢复时不会强行重试。删除代理立即从新配置移除，历史和在途私有引用保留。
