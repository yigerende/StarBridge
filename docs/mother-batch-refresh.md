## 行为

- 刷新全部席位/套餐前读取最新母号状态，只逐个请求已启用项；每次请求携带 `active_only=true`，后端再次核对启用状态，停用项在解密代理和访问上游前跳过。
- 本次结果独立显示成功、失败、跳过数量，单项失败继续其余查询。席位汇总及快照覆盖数仅包含启用母号；历史累计完成数仍包含全部母号。
- 管理员仍可在单个母号详情手动查询停用资源。已知 AT 过期在查询上游前返回明确提示；上游 401 显示“母号凭据已失效，请更新 Session / AT 后重试”，使用业务错误 400，不误作星桥登录失效。
- 共用前端请求解析对 HTML、空响应和损坏 JSON 返回中文状态提示，不展示网关页面或解析器异常。原 JSON 业务错误和 AbortError 保持。
- 不刷新或修改母号凭据，不改变启停、代理、调度、订单、钱包或原执行核心。失败保留原快照，快照继续注明历史查询性质。用户 API 文档不加入内部管理员参数。
