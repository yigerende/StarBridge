# 母号取消自动续费

代退资源与调度 → 母号管理，每行增加「取消自动续费」入口，打开该母号管理弹窗的「自动续费」页。先查询状态，显示自动续费、当前套餐到期时间和查询时间，再由管理员确认取消。关闭后在母号列表显示已取消；上游结果不明显示待核实，仅提供查询结果。

## 接入与边界

- 用户提供的 HAR 展示新版管理门户的订阅查询、deactivate 预览及 update，预览为到续期时生效；返回后 will_renew=false。该 HAR 未保留门户 Cookie，不能直接复用其中的门户登录或 reviewed_terms 常量。
- 本功能复用星桥已有的 AT 订阅通道：后端先校验母号 AT 的邮箱与团队及 /me，再 GET /backend-api/subscriptions?account_id=当前母号团队，POST /backend-api/subscriptions/cancel，最后重新查询 will_renew。使用当前母号加密保存的凭据与专属代理，不使用 HAR 的真实账号、凭据或订阅 ID，也不切换子号代理。
- 新增两个仅管理员接口：POST /api/admin/refund/mother-management/{id}/renewal/check 与 /renewal/cancel。取消请求必须携带当前 team_id，拒绝过期表单及额外字段，普通用户与客户 API 密钥不可调用。这是运营资源操作，不加入客户 API 文档。
- 与现有代退执行和母号管理共用团队租约，母号正在代退或同团队已有管理操作时返回409。取消前持久化待核实标记及审计，单次只发一个写请求；超时、5xx、响应不完整后只查询，不再次取消。只有明确关闭或无有效订阅时确认完成；明确4xx拒绝显示HTTP状态，允许后续人工重试。
- 续费快照保存在现有 management_json 的 renewal 字段，绑定当前 team_id，不增加数据库或后台任务，不创建业务订单，不动钱包、母号启停或原代退核心。未知结果跨刷新与重启保留；可反复点击查询状态。
