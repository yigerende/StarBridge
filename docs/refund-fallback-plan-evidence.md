# 兜底套餐核验等待与诊断字段

2026-11-14。用户授权实现、推送 GitHub 并更新正式。

## 执行位置

在既有套餐兜底流程完成移出确认、重新登录个人账号并校验身份后，等待 `resource_recovery.fallback_plan_wait_seconds`，然后执行 `/me` 身份核验和 `/accounts/check/v4-2023-04-27` 套餐核验。默认5秒，允许0～60秒，0表示不等待。位于代退资源与调度 → 调度与恢复 → 停用待核实：移出后套餐兜底。

每次兜底登录（包括核验重试）都应用此等待；登录或身份校验失败不发套餐请求。此项独立于进入团队前的 `post_login_wait_seconds`。缺失字段才初始化5，不覆盖其他正式设置。

原套餐判定未放宽：匹配当前个人账号、结构为personal、套餐与有效订阅状态一致才接受；当前Free且明确无有效订阅时允许保留历史付费套餐标签。未知/缺失/矛盾仍按原规则重试核验，不当作成功。原单、冻结、次数、间隔、核验专用分支及结算规则保持，历史失败单不重放。
