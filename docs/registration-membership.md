# 注册会员减免与用户导航调整

## 修改范围

- `frontend/src/App.vue`：订阅办理下级为结账链接、续费管理；注册办理下级为我的账号。支持展开收起、选中状态、直接访问子页自动展开，以及移动端菜单。
- `frontend/src/Customer.vue`、`components/LedgerTable.vue`：注册与订阅分别展示资金流水；注册不显示银行卡费用，支持搜索注册订单号。钱包余额仍统一。
- `services/gpt-register/integration/pricing.js`：读取星桥会员配置、当前等级、有效期和账户服务费设置，供注册商品报价与下单共同使用。
- 注册平台 `api.js`、`orders.js`、`db.js`、`integration/schema.sql`、`wallet.js`：接入会员报价、订单报价快照和两位小数结算。原注册引擎与原管理台不修改。
- 注册 `Workspace.tsx`：右侧显示标准单价、会员等级、减免比例、优惠金额、优惠后单价、预留总额及冻结后可用余额；报价失败时禁止新单并提供重试。
- 注册财务趋势、风控对账、星桥流水投影与迁移脚本：金额先乘 100 再转换最小单位，避免丢失小数；迁移指纹忽略等值数字的末尾零。
- 注册 OpenAPI、整合清单与测试：文档声明积分支持两位小数；新增计价、结算、迁移与界面验证。

## 计价规则

注册原价仍来自注册配置，标准账号与 OAuth 账号分别定价。使用星桥当前会员的 `discount`（例如 95 表示减免 5%），按星桥最小单位四舍五入。账户统一服务费专属价优先；订阅套餐专属价不会套用到注册服务。

本次沿用星桥现有会员升级依据：已结算订阅消费，以及运营指定等级和有效期；未改变会员成长规则。注册和订阅的会员配置、人工等级、过期处理和账户服务费一致，专项测试直接调用 Python 会员计算器与注册报价比较。

示例：原价 5 积分、会员减免 5%，优惠后 4.75 积分；3 个账号冻结 14.25 积分。成功交付 2 个扣 9.50 积分，失败 1 个释放 4.75 积分。下单时保存会员及报价快照；之后改等级、改价、幂等重试均不改旧订单费用。

## 数据兼容

只将注册订单单价、已扣/已释放金额、注册流水差额及奖励基数扩展为两位小数；旧数值不变，旧订单报价快照为空。统一钱包仍以整数最小单位记账。原注册伙伴奖励继续按整积分向下取整，基数使用实际优惠后扣费。

数据库升级与触发器更新在现有初始化事务和锁内执行。历史迁移按原始列逐表校验值，整数 `5` 与两位小数 `5.00` 视为相同。所有验证使用隔离库；本次只更新本地预览。
