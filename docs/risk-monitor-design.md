# 风控监控整理（2026-11-10）

用户反馈风控监控页面杂乱，在“更新最新版本”任务中继续完善并发布。

## 页面与规则

- 统一为一组统计卡和四个视图：访问事件、业务告警、IP 封禁、访问统计。不按项目拆分页面。
- 删除页面底部嵌套的原注册风控面板。原面板中的客户/API 密钥频率规则与客户暂停，仅由 `risk.consume` 执行；StarBridge 集成模式已经跳过此函数。这些无效配置不再作为可用限制显示，统一 IP 规则仍由 Python 网关执行。
- 原业务告警、手动检查、分页、详情、标记核查、访问统计、自动刷新和有效告警参数改为统一原生界面，仍调用现有管理员接口。业务告警保留原有覆盖范围；访问统计统计的是原业务监控已记录的请求，不冒充全站 HTTP 流量。
- 原注册核心、Python 限流、管理员豁免、鉴权、数据库结构及正式配置均不改动。未增加迁移或新风控后端。
- 统一 IP 封禁使用既有管理员接口，支持添加、按 IP/原因搜索和二次确认解除；不能封禁操作者当前 IP 的校验仍由后端执行。
- 风控配置保留18个字段，按访问请求、登录验证、邮件验证码、账户与记录分组。告警设置保留有效检查与记录参数；保存时保留未展示的原字段和版本号，避免覆盖存量设置。
- 查询区分草稿与已应用筛选，翻页不会偷偷应用未提交的搜索；失败保留已加载数据。并发刷新取消旧请求，卸载停止请求与计时器。
- 手机端列表改为带字段名称的记录卡，配置表单单列，保留完整详情。
