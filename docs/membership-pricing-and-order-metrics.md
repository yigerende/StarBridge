# 2026-11-11：会员减免、专属价格与订单展示

用户明确要求完成本轮全部改动，并将全部未提交代码推送 GitHub、更新正式环境。包含另一会话交接的付款前网络重试修复，见 subscription-proxy-network-retry.md。

## 计价与配置

- 账户管理分别设置标准注册、OAuth 注册、各订阅套餐和代退的专属价格。0 有效，留空清除；专属价格优先于会员与标准价格，已受理订单保留原费用快照。
- 新表 user_service_prices 保存注册和代退专属价格。既有 user_product_prices 保存订阅套餐专属价格；users.fee_override 只作为订阅默认专属价格，不再应用于注册和代退。保留原数据库值，不为已有账户自动生成其它服务专属价。
- 会员管理新增减免范围：标准注册默认参与，OAuth 默认不参与，订阅按启用且当前流程可用的套餐设置，代退单独设置。新增 settings.membership_pricing；已有其他设置不覆盖。
- 减免范围入口等待实际配置加载完成后才可打开；刷新套餐列表时重新初始化表单，避免慢请求下误保存默认规则。浏览器回归通过延迟响应验证此边界。
- 用户办理页右侧仅在设置时展示“专属价格”；不参与会员减免时始终展示“此服务不参与会员减免”，即便同时存在专属价格。
- 会员标识支持 1～32 位中文、大小写字母、数字、下划线、短横线。改名以显式原标识映射，在同一事务同步指定等级账户，保留有效期；不允许删除仍被有效指定的等级。
- Python 订阅/代退报价与 Node 注册报价/受理使用同一配置、会员和钱包。原注册引擎和 HUIXU runtime 未改。

## 状态和时间

- 付款成功且订阅核实生效后，取消续费失败不改变主结果“订阅成功”；续费独立显示“续费待确认”。缺少付款或激活证据时不能提前标记订阅成功。
- 运营概览默认今天，三个业务卡展示期间完成笔数与净结算积分；订阅付款成功计完成。完成笔数以期间创建订单为范围，净结算按期间扣费减退款。
- 办理总览支持今天、昨天、本周、本月、全部与自定义；北京时间周一作为周起点。
- 两端订阅列表展示开始执行到付款成功耗时，下一行总耗时；两端代退列表展示总耗时。总耗时含排队和重试，在途显示已用时间；历史缺证据显示空值，不用可变 updated_at 猜测。
- 用户后续追加两端办理总览的“总耗时”列，同时加入记录详情和用户 API。分页后按业务批量补充，沿用同一只读快照；注册取最后交付/释放账本时间，独立续费取最后结束事件，订阅和代退复用订单中心口径。没有逐单查询，也不补写历史数据。
- 用户代退菜单后增加禁用的“自动办理”入口，预留注册 → 订阅 → 推送 Sub2api → 代退流程。
- 订阅扣费时点未改：提交时冻结，明确付款成功后扣费，再继续核实订阅与取消续费。付款结果未知保留冻结并只读核实；paid_at 与账本幂等防止重复扣费。
