# 订阅手动代理主备与地区展示

2026-11-11：用户要求订阅手动代理只在网络/代理故障时切换，增加 1024、711 厂商，完成后推送和更新正式。国家代理拉取问题用户已自行解决，本轮不修改其供应商地址、凭据、来源及库存。

每条手动代理可设置主用（0）或备用顺序（1～100）。先按订单国家匹配，再按主备顺序、同顺序优先代理和权重选择；IPRoyal 动态模板保留原跨国家生成能力。主用容量不足只排队，不因繁忙跳到备用。停用或故障冷却时依次选择备用。默认冷却 300 秒，可在手动代理配置中设为 10～3600 秒。

明确网络超时、DNS、连接/代理隧道错误触发冷却；401/403/407/429、账号授权、验证码、证书校验错误、支付拒绝和本机连接池繁忙不触发换绑。每笔订单记录已失败代理，重试优先选未失败的资源。到期只放行一笔恢复试用，其余订单走可用备用；成功提链或明确付款成功后解除故障。故障版本隔离保证旧订单的晚到成功不会清掉新故障，管理员修改凭据后旧订单也不会污染新资源。

安全换绑只发生在付款尚未提交的原网络重试阶段：释放本单租约、清除旧结账上下文，下一轮分配备用并重新提链。付款防重标记、原订单、地区/账单快照、冻结资金均保留；付款已提交或结果未知只核实原交易，不因换代理重付。已付款后续沿用原绑定。完整 cs-live 一体流程提交后同样不重放。独立续费管理仍使用指定全局代理，不冒用订阅国家的主备。

后续用户明确提供1024/711参数结构并要求所有手动动态代理按支付国家生成会话，已统一适配，支持每条资源配置粘性时长，见 [账户与手动会话更新](account-filters-and-manual-sessions.md)。管理接口支持新增和回显，普通用户不获得代理凭据。原注册核心和代退核心未改。

订阅地区目录独立保存。供应商国家同步只更新供应商支持列表，不再增删订阅地区；正式现有 211 条保留名称、币种、排序、状态。各国价格页始终按此目录显示，缺少报价的地区显示“暂无参考价”。手动/独立会话的支付选择按已启用订阅地区；国家代理按有库存的具体国家显示，不因 GLOBAL 扩大到所有国家，名称币种优先取订阅目录。原执行流程的国家支持边界和订单快照继续保留。

验证：10 项新手动主备测试、5 项原网络重试、3 项新地区隔离、5 项国家池（同模块额外运行9项统一钱包/权限）、44 项付款/核实/恢复/地区/价格回归及2项订阅受理执行通过。包含50并发半开仅1笔主用、8并发重复故障仅计1次、本单租约隔离、全冷却排队不扣重试、未知付款不重放。前端生产构建、4项代理/地区浏览器场景及3项价格逻辑通过，1440/1024/390宽无页面溢出。文档33操作/358示例通过；原核心来源校验通过。没有真实付款、退款或正式压测。

发布保留正式数据/配置/密钥与当前代理模式；默认原手动资源全部为主用，管理员自行设置备用次序。备份与上线结果记入父目录正式 runbook。
