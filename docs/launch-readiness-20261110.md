## 已实现

- 用户“办理总览”在资金中心之后，运营“办理总览”在订单中心之后。全部历史记录服务端分页，包含注册、订阅、结账链接、独立关闭续费及代退；独立续费归入订阅。支持搜索、业务、状态、起止日期，运营可选是否包含管理员订单。
- 列表突出业务/项目、办理邮箱或注册数量、进度、实际结算、当前冻结及时间；运营增加所属客户。顶部显示全部、进行中、已完成、需核实，以及业务数量、部分完成、失败、取消、注册交付数，运营另有涉及客户数。统计覆盖全部筛选结果，金额取实际账本。手机端使用卡片布局，详情支持转到原订单/续费记录。
- “办理总览”独立功能开关；用户仅查询本人数据。关闭钱包时总览不返回费用，关闭订单中心时不提供完整订单入口，已受理记录仍可通过开启的总览查询。
- 运营顶部右上角增加“原注册平台”，新窗口打开；普通用户不加载管理员入口组件。原页面、资源和核心 API 均继续由后端管理员鉴权，匿名、普通会话、客户 API 密钥不能访问。
- 密钥可再次复制、修改用途名称。数据库保存加密原值，列表不返回原文或密文；复制响应 no-store，复制/改名/撤销记审计，不能操作他人的密钥。撤销、重置密码、停用/删除账户清除密钥密文。此前只存摘要的密钥无法还原，下一次有效 API 调用时加密保存，原密钥持续有效。
- 请求限流统一按可信来源 IP，不同 IP 独立计数；同一 IP 的网页、公开 API 和注册接入按对应限流类别累计，不能通过切换账户或密钥绕过。真实鉴权管理员豁免请求频率限制。排队容量、执行并发、幂等和业务权限继续执行。429 返回剩余等待时间，事件写统一风控。
- 风控表单补齐总入口、业务接口、下单、兑换、Session 检查、领取/导出、登录、注册、密码重置、滑块获取/验证、邮件分钟/每日限额、邮箱重发间隔。已保存限额保持原值，新增项使用默认值。
- API 鉴权结果仅在单个请求复用；SSE 每次通知/心跳重新检查会话撤销。密钥访问时间最多每分钟更新，避免每个读取请求争写同一行。
- 数据库连接池保留突发流量扩展出的连接，避免频繁重连；增加办理账本组合索引及续费用户时间索引，消除总览账本关联的重复扫描。
- 注册私有文件路径返回 404；原先该路径返回的是 SPA HTML，并未读取配置文件。
- 客户 API 文档 2.5.0，33 个操作，增加 GET /api/v1/activity、字段、筛选、分页和限流说明。没有加入运营接口或管理员使用说明。
