# 订单中心与代退办理界面（2026-11-10，仅本地）

本轮按用户要求统一注册、订阅、代退三个业务的订单界面，并重做代退办理。没有提交、推送或正式部署；继续使用隔离预览 http://127.0.0.1:18970。

- `records.css` 改为应用公共加载，直接打开注册或代退也具备完整表格样式。`order-center.css` 限定订单中心路由，统一用户和运营页面的面板、标题、搜索、筛选、按钮、表头、空状态与分页。控件高度 38px，搜索图标左侧内嵌。保留各业务的筛选条件、查询方式、分页参数和订单操作。
- 代退采用申请表单与费用确认两栏；单个和批量切换、TXT/CSV 导入、授权确认、幂等重试、成功清理密码等功能保留。显式修复全局 label 竖排和 input 宽度对搜索框、授权复选框的影响；小屏单列。
- 代退继续使用统一会员计算和共享钱包，不新增会员或钱包体系。右侧始终展示等级、标准费、会员/专属价减免、数量、本次冻结与可用余额。报价新增 `price_source`，开放文档补齐其说明。
- 菜单、业务 Tab、业务图表、接口文档示例和接口组顺序为注册 → 订阅 → 代退；未选择业务时默认注册，已有明确业务选择保留。OpenAPI 下载也按业务排序。
- 此前的站点设置“界面与导航 → 用户端二级菜单默认状态”保留，默认收起；可保存为展开，直接进入子页面展开所属菜单。
