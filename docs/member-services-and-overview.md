# 会员报价与运营展示（2026-11-11）

- 会员中心“我的服务报价”按注册、订阅、代退展示。注册包含标准账号与 OAuth 账号，订阅包含可见套餐，代退使用统一服务费。报价复用实际会员与专属价格规则；专属价为零也有效，不参与会员减免的服务明确提示。
- `/api/membership` 与 `/api/v1/membership` 新增 `services`；原 `products` 仍为订阅套餐，既有调用不变。用户文档更新为 2.6.1，仅描述客户字段与用法。
- 注册接入计价同步统一会员成长：实际消费加有效成长补足值达到下一档后，注册与 Python 订阅、代退采用相同等级。原注册执行核心不改。
- 版本与更新组件仅在运营控制台展示；管理员进入用户中心也不展示。普通用户不能读取或操作后台更新接口，公开资料不返回运行版本、仓库或更新状态。
- 运营概览业务趋势移到最近订单之后；待处理事项移到日期筛选区右侧，以数量按钮展开当前待办，保留原跳转与统计口径，支持键盘和移动端。
- 运营账户列表在冻结余额后增加“已用余额”：统一账本全部历史扣费减退费，覆盖三项业务，不受订单删除或当前状态影响，不包括冻结、充值、调账和会员成长补足。仅聚合当前分页账户，不新增余额字段或写入资金。
- 运营安全与配置菜单按注册、订阅、代退资源与调度排列。注册接单限额、并发、邮箱模板、重试和超时从定价页移至注册资源与调度；定价页只保存两类标准价格，资源页只保存运行配置，避免互相覆盖。
- 订阅资源与调度增加“订阅流程配置”页签，复用原付款配置接口和全部字段。订单中心移除配置按钮，订阅定价页的流程提示链接统一跳转此页；不改变正式流程或队列设置。
