# 账户筛选、批量设置和订阅手动会话

2026-11-11 用户追加账户搜索筛选、批量专属价格与会员、10/50/100/500 分页，以及所有手动动态代理以用户支付国家为准、逐资源粘性有效期。本轮沿用发布授权，完成后提交 GitHub、更新 StarBridge 正式环境。

## 账户管理

- 服务端对邮箱、名称、账户 ID 做大小写不敏感的字面包含搜索，可组合角色、状态和实际生效会员等级；没有原 500 条截断。默认10条，界面可选10/50/100/500，服务端上限500。
- 自动消费等级、有效指定等级和已过期指定等级按统一会员规则计算；总数和页数据使用同一只读快照。排序为创建时间、ID 倒序。空结果及删除后超出末页自动返回有效页码。
- 只取当前页专属价；复用等级配置避免每个账户重复查询。切换筛选/页码清空选择，旧请求响应不能覆盖新结果。
- `POST /api/admin/users/batch-settings` 仅管理员可用；显式 IDs 最多500。注册标准/OAuth、订阅默认/开放套餐、代退支持分别设置、清除；未提交字段保持。会员支持指定等级/有效期或恢复自动等级。0为有效专属价，null为清除。
- 批量变更同事务锁定账户，字段错误、已删除账户均整体拒绝；逐账户记录审计。钱包、现有订单价格和执行状态不修改。客户文档不展示管理接口。

## 手动代理

统一 `backend/manual_proxy_sessions.py` 供三个订阅流程调用。IPRoyal、CLI、1024、711 动态代理都按订单的支付国家覆盖地址中的旧国家，按每笔订单生成会话。后台资源地区只用于动态代理的独立检测；静态代理依旧按实际地区匹配，不能靠参数将固定 IP 改到其他国家。

| 厂商 | 国家 / 会话 / 时长 | 允许时长 |
| --- | --- | --- |
| IPRoyal | 密码 `_country-xx_session-ID_lifetime-Nm` | 1～10080分钟 |
| CLI / 1024 | 用户名 `-region-XX-sid-ID-t-N` | 1～120分钟 |
| 711 | 用户名 `-region-XX-session-ID-sessTime-N` | 5～180分钟 |
| 其他动态厂商 | 账号或密码中的 `{country}`、`{session}`、`{minutes}` | 1～10080分钟，须符合实际供应商规则 |

711保留原 `sessAuto`，会话为8位数字；原网关/端口/基础凭据保留。供应商即使返回相同会话随机值，也会在事务分配锁内重新生成，避免与未过期订单重用。相同订单继续使用持久化的原地址和到期时间；编辑资源仅影响下一次分配。已付款或结果未知时仍仅核实原交易，不换会话重新付款。原主备/冷却规则继续生效。

新增 `resources.session_minutes` 可空，已有记录读取地址中有效时长，没有则取厂商默认；不批量改写正式凭据。后台保存时持久化所选分钟数。后台资源编辑使用独立地区目录，避免公共支付地区异步覆盖211项管理目录。

格式依据为用户提供的脱敏结构与供应商公开说明；用户真实凭据不进入源码和测试。参考：[711](https://docs.711proxy.com/proxies/proxy-configuration-parameters/session-types)、[1024](https://help.1024proxy.com/dynamic-residential-traffic/session-management)、[CLI](https://help.cliproxy.com/traffic/using-setup)。

## 运营办理总览

“查看”在当前页面直接打开对应业务的完整记录：注册复用原订单详情，订阅复用完整办理记录，代退复用流程及运营处置，独立续费展示任务和事件。关闭后保留总览筛选、日期与页码，不额外加载订单中心列表。用户端仍使用原摘要及完整记录链接。管理续费详情只返回明确列出的展示字段，后端管理员鉴权，不返回凭据。

## 验证

- 6项账户隔离数据库测试：525账户全量搜索/稳定分页、组合筛选、有效会员、权限、字面搜索、50并发读取、500账户批量价格/会员、错误回滚、未选项目及钱包保持。
- 4项会话测试：四厂商格式/国家替换、时长校验、同单复用、跨流程一致、编辑隔离、711随机会话碰撞重新生成。主备/冷却与未知付款防重付10项回归通过。
- 前端生产构建和浏览器实际交互：查询/筛选/分页/重置、过期响应隔离、跨页选择清空、批量价格/会员请求、逐代理时长保存；桌面1440和手机390无页面横向溢出。国家代理与原独立会话界面回归通过。
- 运营总览四类详情在1440/390宽度下直接打开、关闭保留第二页、404错误及用户摘要回归通过；新增续费详情验证未登录401、用户403、管理员200、缺失404及敏感字段不泄露。
- 测试在本机18983临时库和模拟浏览器接口执行；不使用用户提供的真实代理凭据，不执行真实付款、退款或正式压力测试。
