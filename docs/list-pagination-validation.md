# 两端列表分页与刷新记忆

本轮补齐先前未完成的分页工作，仅在本地实现和验收。没有提交、推送 GitHub、部署或修改正式数据。

## 统一行为

- 记录页统一提供10、50、100、500条选择。数据库记录在数据库中筛选、全量排序再 LIMIT/OFFSET；有限的配置集合在服务端筛选排序分页后返回，浏览器不对当前页进行假排序。
- 按账户和列表保存页码、每页条数、已选择的排序字段/方向及筛选条件。换筛选或条数回第一页，表头再次点击反向排序；排序使用白名单及稳定的并列顺序。
- 操作按钮、完整凭据、复杂详情和运行中的耗时不作为排序键。卡片形式的交付分组、公告和国家池用排序按钮；固定配置表单、指标卡、仪表盘最近记录摘要、订单时间线和文档参数表保持原用途。
- 控件记忆不保存业务行、账号凭据、Session、令牌或密钥。授权、领取有效期、业务功能开关及数据归属继续由后端校验。

## 本轮补齐

1. 会员“我的服务报价”原来隐藏翻页且默认截取前12条，改为独立的服务端分页列表，支持业务/开放状态/服务名筛选和价格排序。网页不再每次读取成长明细都重复传送完整报价，公开会员API保留原完整响应。
2. 独立会话/国家代理、用户资金中心、站点设置记住选中页签；注册财务刷新不再无条件清空页码。
3. 注册列表的服务类型及账号搜索完整恢复。领取链接的订单号使用独立筛选范围，不被另一订单或普通账号页的旧筛选覆盖，支持刷新及浏览器前进/后退。
4. 运营交付订单分组增加订单号、客户、服务、数量、最近交付排序；供应商增加成功率、收码率和统一币种成本排序；国家池手工地址增加排序入口。
5. 客户资金流水保留筛选；各国价格排序选择器与实际表头排序一致，避免表头已改排序却仍提示价格升序。
6. 运营资金业务明细切换业务回到第一页，移除目标业务没有的排序字段；结果减少后自动回到有效页码。账户流水说明同步改为全部流水，不再提示只显示最近300条。
