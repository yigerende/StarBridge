# 资金报表、公开订单计数与登录页（2026-11-12）

本轮在独立工作区 `finance-reports/starbridge` 完成，基于 `0c5fc3c`。用户后续明确授权推送 GitHub 并更新正式环境；本批合入最新主分支后沿用预构建、空闲检查、备份切换流程。只读取星桥自己的数据库，原注册与代退执行核心不改，不导入旧项目业务数据。

## 资金中心

- 运营端重做为客户报表、资金总览、业务明细；每次进入默认打开第一项客户报表，参考 HUIXU 按客户对账的结构。原注册成本报表保留在注册业务卡的“成本明细”，独立筛选，避免把积分净消费误称为利润。
- 日、周、月、年及自定义范围，使用北京时间自然周期，周一为周首。自定义最多 366 天。
- 默认不含管理员，可包含管理员、排除指定账户、搜索称呼/邮箱/ID、筛选账户状态和本期有流水/订单的客户。排除名单按登录账户保存在本机浏览器。
- 卡片、趋势、各业务及导出均覆盖全部匹配记录；客户和流水列表采用服务端 10/50/100/500 分页与白名单字段排序。
- 入账区分充值、兑换和人工加款；人工扣减、伙伴奖励另列。净消费只用实际 charge 减 refund。冻结、未结算释放分别计数，不当成消费或退款。
- 冻结与可用变动优先采用账本的明确变动字段；缺失时先按完整账户历史计算相邻快照差额，再截取日期范围，保留跨天冻结释放。
- 当前余额/冻结是当前账户值；流水按发生日期，订单按提交日期、显示当前进展。订阅付款成功计入完成，与后续续费状态独立。
- 软删除账户/订单保留在财务历史中。新读取接口全部要求后端管理员鉴权，无写资金能力。报表查询使用只读一致性快照。
- CSV 导出按相同条件覆盖全部匹配结果，上限 50,000；金额用 Decimal 将分转成两位积分，UTF-8 BOM，防止账户名称等文本被当成电子表格公式。

## 公开订单计数和登录注册

- `GET /api/public/order-counts` 只返回 `total/registration/subscription/refund/updated_at`，不返回账户、资金、凭据或成功/失败分类。
- 计数包含管理员、全部订单状态和软删除历史。注册按订单笔数而非账号数量；订阅只计 `workflow=subscription`，独立结账链接与续费任务不重复计入；代退按申请笔数。
- 每进程 60 秒聚合缓存，锁内只刷新一次；数据库失败短暂退避 5 秒。查询超时 5 秒。页面独立获取计数，不阻塞登录，后台暂停轮询；失败显示横线和暂不可用，不显示假零。
- 登录和注册共用深色左侧展示区、光环轨道动画及动态计数，右侧表单。支持手机、暂停动效及系统减少动态效果。原用户名/邮箱登录、滑块、邮箱验证、注册邀请和找回密码流程保留。
- 用户顶部公告左侧增加累计计数，可展开查看注册、订阅、代退。运营界面不重复放公开计数。

## 账户统计与自动刷新

- 账户管理顶部六张卡：账户总数、正常账户、已升级会员、可用余额、冻结余额、已用余额。停用数量、管理员数量、基础等级数量和冻结账户数量辅助展示。
- 所有卡片随现有搜索/角色/状态/实际会员筛选变化，覆盖全部分页。会员按现有实际成长和有效期限计算；已用余额使用所有业务历史实际扣费减退费，不使用会员成长或人为调整的成长值。
- 用户/运营办理总览、用户/运营资金中心共用自动刷新控件，默认开启 10 秒，支持 5/10/30/60 秒、关闭及立即刷新。按账户/页面记住选择。
- 保留筛选、分页、排序、Tab 和正在填写的内容；后台页面暂停，详情/编辑中暂停；前次请求未完成不叠加轮询。明细子列表的刷新也不打断尚未完成的请求。
